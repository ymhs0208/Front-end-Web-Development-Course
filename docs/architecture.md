# 程式架構與修改位置

## JavaScript 分工

| 位置 | 責任 |
| --- | --- |
| `dist/js/main.js` | 啟動、組合模組、分派操作事件 |
| `dist/js/data/` | 題庫與特大／最大模式的短版選項 |
| `dist/js/core/` | 路由、儲存、抽題排序、練習進度與獎勵計算 |
| `dist/js/pages/` | 首頁、自選情境、獎勵、錯題與說明頁 |
| `dist/js/components/` | 大方塊、步驟圖示、勳章、提示等共用元件 |
| `dist/js/features/` | 作答流程、分段閱讀、字級與朗讀、對外整合 |

`engine.js` 為純函式；`store.js` 統一寫入設定和紀錄。作答模組透過回呼更新頁面，避免與路由互相匯入。部分舊版元件保留相容性，不代表目前頁面提供所有舊功能。

## 首頁

`pages/home.js` 提供一個主要練習按鈕與三個次要連結，`css/home.css` 獨立處理首頁排版；與情境列表的四方塊樣式分開。首頁將整張可點擊的開始卡片排在用途標語前方，以播放圖示、開始練習和每次 3 題呈現。卡片使用同一個 button，點圖示、文字或留白都能開始。DOM 與視覺順序一致。字體依四級設定逐級放大：用途標題維持同一行，手機為 22／23／24／25px、開始按鈕 32／34／36／38px、次要入口 26／28／30／32px、每次題數說明 24／26／28／30px。樣式選擇器須高於舊版共用按鈕與導覽規則，避免選擇更大字反而縮小。

已實際檢查 320×667 最大字模式，所有入口均能完整顯示，四個入口都可見且無橫向溢出；主要文字維持高對比。這是畫面與操作檢查，尚未經長輩真人測試。

## 共用頁首

頁首 HTML 位於 `dist/index.html`，獨立樣式位於 `dist/css/header.css`，易讀覆寫位於最後載入的 `dist/css/low-vision.css`。使用 `header-*` 類別，避免舊版樣式影響。工具列提供可回首頁的網站名稱、朗讀按鈕、字體及語音選單；手機分為名稱列和設定列，作答時隱藏名稱及頁面朗讀，沿用本段朗讀按鈕。字體與語音保留原本 select ID，沿用設定及事件。

## 共用配色

`css/theme.css` 集中定義單一紫色主題；最後由 `css/low-vision.css` 加深文字、主按鈕與邊界。使用淺紫背景、白色卡片、淡紫圖示，紫色實底保留給主要操作；次要操作和返回按鈕使用白底描邊。易讀樣式也統一各頁的文字級距，保持操作順序。獎勵星星保留金色，作答正誤保留原本的提示語與狀態圖示。

## CSS 分工

`dist/style.css` 是樣式入口，依序載入基本、響應式、作答、無障礙、簡化流程、iOS 風格、圖示教學、電腦版、分段閱讀與獎勵樣式。載入順序會影響覆寫結果，請在對應功能檔案修改。

## 路由與資料

- `#home`：首頁。
- `#practice`：自己選題。
- `#exercise`：作答，有進度才可進入。
- `#rewards`：我的獎勵；舊 `#review` 自動轉到此頁。
- `#mistakes`：保留的錯題筆記路由。
- `#guide`：使用說明。

練習優先排序為錯題、未練習、較少練習。最近一次答對的題目會移出錯題清單。每筆有效作答紀錄都獲得一顆安心星，答錯及重複同題也計入；星星沒有題庫數量上限。勳章仍以不同情境及類型判斷。夥伴在 3 顆星時披上披風，9 顆星（目前題庫數量）時戴上皇冠，之後仍可繼續收星。既有紀錄直接重新計算，不做寫入遷移。成長規則在 `core/rewards.js`，插圖在 `components/companion.js`，動畫尊重減少動態效果設定。

`localStorage` 使用 `vault-training-v1` 保存紀錄與設定；`sessionStorage` 使用 `vault-exercise-v1` 還原同分頁練習進度。保留既有 key，避免升級後遺失資料。

## 網站入口

GitHub Pages 使用根目錄 `index.html` 轉到 `dist/`，保留網址查詢參數與 hash。原始碼可直接提供靜態服務，無須產生另一份建置目錄。調整資料夾路徑時需同步檢查此入口、HTML、CSS 和 ES Modules 的相對路徑。

## 視力較弱使用者的易讀模式

新訪客預設特大字（level 2），既有字級、語言與作答紀錄保留。四級內文為 26／28／32／40px，選題與答案為 28／30／34／40px；首頁為保持主要入口可見，使用各自的字級規則。頁首選單文字至少 26px，主要操作至少 64px 高，聚焦框加深。小螢幕的選題、教學與勳章改為單欄；文字完整換行，不省略內容。

特大／最大字以實際可用高度分段呈現題目與解說，保留上一段、朗讀本段、下一段；計算時納入完整控制列與底部返回列。答案保留完整文字，必要時垂直捲動。最小螢幕最大字可能每段只有兩行，優先保留可辨識字體及完整內容。新模式不自動開啟語音；手動按朗讀可聽當頁操作提示，換頁或再按一次即停止。尊重系統減少動態效果。

驗證涵蓋 320×667、390×844 與電腦版，檢查首頁、選題、題目／解說、獎勵及說明；不等於長輩真人或所有視力狀況的可用性保證。

## 簡化獎勵卡

獎勵主卡只保留夥伴插圖、累積星數和「繼續練習」按鈕，移除重複稱號、鼓勵文字、九顆進度星與下一階段目標。夥伴仍依原本星數顯示披風與皇冠；星數與勳章計算不變，錯題優先排序不變。集星與勳章規則統一放在預設收合的「獎勵怎麼拿？」；頁面朗讀只說星數與練習入口。版面覆寫集中於 `css/simple-rewards.css`。

角色插圖由 `components/companion.js` 產生，採圓潤星形、大眼睛與腮紅，三階段沿用同一角色，依星數加上披風、皇冠。手機角色寬度提高至 100px；星數單位簡化為「顆星」，保留大字與單一練習按鈕。

## 電腦版版面調整

`css/desktop-refinement.css` 僅在 1024px 以上生效，最後載入。內容寬度統一為 1200px，頁首朗讀按鈕靠近字體與語音設定；首頁左側為開始練習與用途標語，右側為三個功能入口。獎勵頁左側放大夥伴與星數，右側排列勳章；選題保留雙欄，作答區限制閱讀寬度。返回按鈕縮為靠左的大按鈕，保持首頁 hidden 狀態。手機版不受此檔影響。此輪瀏覽器操作因 Work 設定停用，僅完成靜態檢查，尚未完成實際桌面視窗驗證。

## 高齡易讀視覺整理

`css/senior-design.css` 最後載入，統一安靜底色、深色文字、明確框線與焦點框。首頁 `home-main` 集中用途、簡短操作說明、開始按鈕；桌面與次要功能左右分區，手機依 DOM 順序單欄顯示。用途標語仍維持一行，開始練習保持單一 button；語音、字級、星數與作答資料不變。說明頁練習入口移到語音詳細說明之前，避免入口被長文推後。這輪 Work 設定停用瀏覽器操作，已做模組及既有測試，尚未完成實際畫面驗證或長輩真人試用。

## 多裝置排版

`css/device-layouts.css` 補齊平板寬度 761–1023px：設定列兩欄、一般選題與勳章兩欄，最大字改為單欄，教學採插圖與文字橫列。手機維持單欄；1024px 起採桌面配置。高度不超過 560px 時，返回列改放在內容之後，避免橫向手機或低高度視窗遮住作答。各斷點保留使用者字級與內容，不限制瀏覽器縮放，安全區留白支援手機底部。既有練習控制器在旋轉或視窗尺寸改變時重新計算分段。這些為響應式實作規則，因瀏覽器操作停用，尚未完成實機畫面驗證，不能宣稱所有裝置皆已驗證。
